## 新增需求

### 需求:IT人员可远程执行命令

总部 IT 人员必须在 Web 管理平台向在线的门店电脑发送命令或脚本并执行。

#### 场景:执行单条命令
- **当** IT 人员在命令输入框输入 `ipconfig /all`
- **当** IT 人员点击"执行"按钮
- **那么** 系统弹出二次确认对话框
- **当** IT 人员确认执行
- **那么** 命令发送到门店客户端执行
- **那么** 执行结果返回并显示在 Web 界面

#### 场景:执行脚本文件
- **当** IT 人员上传一个 `.bat` 或 `.ps1` 脚本文件
- **当** IT 人员点击"执行"按钮
- **那么** 系统弹出二次确认对话框，显示脚本内容预览
- **当** IT 人员确认执行
- **那么** 脚本发送到门店客户端执行
- **那么** 执行结果返回并显示在 Web 界面

#### 场景:门店离线时执行命令
- **当** IT 人员向门店发送命令
- **当** 该门店客户端离线
- **那么** 系统提示"门店离线，无法执行"

### 需求:远程命令执行需要二次确认

所有远程命令执行操作必须经过二次确认，防止误操作。

#### 场景:二次确认对话框
- **当** IT 人员点击"执行"按钮
- **那么** 系统弹出确认对话框
- **那么** 对话框显示即将执行的命令内容
- **那么** 对话框显示目标门店名称
- **当** IT 人员点击"确认执行"
- **那么** 命令发送执行
- **当** IT 人员点击"取消"
- **那么** 命令不执行

### 需求:命令执行超时处理

命令执行必须设置超时时间，防止长时间无响应。

#### 场景:命令执行超时
- **当** 命令发送到门店客户端
- **当** 60 秒内未收到执行结果
- **那么** 系统标记该命令为"执行超时"
- **那么** Web 界面显示超时提示
