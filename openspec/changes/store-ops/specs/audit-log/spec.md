## 新增需求

### 需求:记录远程桌面连接日志

系统必须记录所有远程桌面连接操作的审计日志。

#### 场景:记录连接开始
- **当** IT 人员开始远程桌面连接
- **那么** 系统记录日志：操作人、操作时间、目标门店、目标主机、操作类型（远程桌面连接）

#### 场景:记录连接结束
- **当** 远程桌面连接断开
- **那么** 系统记录日志：连接时长

### 需求:记录远程命令执行日志

系统必须记录所有远程命令执行操作的审计日志。

#### 场景:记录命令执行
- **当** IT 人员执行远程命令
- **那么** 系统记录日志：操作人、操作时间、目标门店、目标主机、命令内容、执行结果

#### 场景:日志内容完整
- **当** 命令执行日志被记录
- **那么** 日志包含完整的命令内容（不截断）
- **那么** 日志包含执行结果或错误信息

### 需求:日志保留期限

审计日志必须保留 3 个月，超过期限自动删除。

#### 场景:自动清理过期日志
- **当** 审计日志超过 3 个月
- **那么** 系统自动删除该日志记录

### 需求:IT人员可查看审计日志

IT 人员必须能够在 Web 管理平台查看审计日志。

#### 场景:查看日志列表
- **当** IT 人员进入"审计日志"页面
- **那么** 显示日志列表，按时间倒序排列
- **那么** 列表包含：操作人、操作时间、操作类型、目标门店、操作详情

#### 场景:筛选日志
- **当** IT 人员选择筛选条件（时间范围、操作类型、门店）
- **那么** 日志列表按条件过滤显示

#### 场景:查看日志详情
- **当** IT 人员点击某条日志
- **那么** 显示该日志的完整详情
