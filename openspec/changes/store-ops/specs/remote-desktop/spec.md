## 新增需求

### 需求:IT人员可通过Web唤起远程桌面连接

总部 IT 人员在 Web 管理平台点击门店的"远程控制"按钮时，系统必须自动唤起本地 RustDesk 客户端并连接到该门店电脑。

#### 场景:成功唤起远程桌面
- **当** IT 人员点击门店列表中某台主机的"远程控制"按钮
- **那么** 系统通过 `rustdesk://` 协议唤起本地 RustDesk 客户端
- **那么** RustDesk 客户端自动连接到该门店电脑的桌面

#### 场景:IT人员未安装RustDesk客户端
- **当** IT 人员点击"远程控制"按钮
- **那么** 系统提示"请先安装 RustDesk 客户端"

### 需求:门店客户端内嵌RustDesk服务端

门店客户端必须内嵌 RustDesk 服务端组件，安装后无需额外配置即可接受远程连接。

#### 场景:门店客户端启动RustDesk服务
- **当** 门店客户端启动
- **那么** RustDesk 服务端自动启动并注册到总部 RustDesk 服务器

### 需求:远程桌面独占控制

当一名 IT 人员正在远程控制某台门店电脑时，其他 IT 人员必须无法同时控制该电脑，但可以观看或排队等待。

#### 场景:远程桌面被占用
- **当** IT 人员 A 正在远程控制门店电脑 X
- **当** IT 人员 B 尝试远程控制门店电脑 X
- **那么** 系统提示 IT 人员 B "该主机正在被其他人员控制"
- **那么** 系统 IT 人员 B 可选择"观看模式"或"排队等待"

#### 场景:远程桌面释放
- **当** IT 人员 A 断开远程控制
- **那么** 系统通知排队中的 IT 人员 B 可以开始控制

### 需求:直连优先中继兜底

远程桌面连接必须优先尝试 P2P 直连，直连失败时自动切换到中继模式。

#### 场景:P2P直连成功
- **当** IT 人员发起远程连接
- **当** 网络条件支持 P2P 直连
- **那么** 使用 P2P 直连模式建立连接

#### 场景:切换到中继模式
- **当** IT 人员发起远程连接
- **当** P2P 直连失败
- **那么** 自动切换到总部中继服务器转发
- **那么** 连接建立成功
