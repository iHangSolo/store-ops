## 组件说明

### store-ops-server (Go 后端服务)

单体服务，包含：

| 模块 | 功能 | 端口 |
|------|------|------|
| REST API | 管理 API，供 Web 前端调用 | :8080 |
| WebSocket Gateway | 门店客户端长连接管理 | :8080/ws |
| RustDesk Integration | 与 RustDesk Server 交互 | - |

### store-ops-web (Vue 3 前端)

Web 管理平台，功能模块：

- 门店管理（列表、状态、审批）
- 远程桌面（唤起 RustDesk）
- 命令执行
- 软件推送
- 进程监控
- 资源监控
- 审计日志

### store-ops-client (Wails 客户端)

门店客户端，功能模块：

| 模块 | 功能 |
|------|------|
| 连接管理 | WebSocket 连接、心跳、断线重连 |
| RustDesk 内嵌 | 远程桌面服务端 |
| 命令执行 | 接收并执行远程命令 |
| 软件推送 | 接收并安装软件包 |
| 进程管理 | 进程/服务查询和控制 |
| 资源采集 | CPU/内存/磁盘数据采集 |
| 本地存储 | SQLite 存储配置和日志 |

### RustDesk Server

| 组件 | 端口 | 功能 |
|------|------|------|
| hbbs | 21115 | ID 注册/寻址服务 |
| hbbr | 21117/21119 | 中继服务 |

## 数据流

### 门店客户端连接流程

```
门店客户端                    总部服务器                    PostgreSQL
    │                            │                            │
    │  1. WebSocket 连接请求     │                            │
    │  (携带 TOKEN, 设备指纹)    │                            │
    │───────────────────────────►│                            │
    │                            │  2. 验证 TOKEN             │
    │                            │───────────────────────────►│
    │                            │◄───────────────────────────│
    │                            │  3. 验证设备指纹           │
    │  4. 连接成功               │                            │
    │◄───────────────────────────│                            │
    │                            │                            │
    │  5. 心跳 (每 30s)          │                            │
    │───────────────────────────►│                            │
    │◄───────────────────────────│                            │
```

### 远程命令执行流程

```
Web 前端      总部服务器      门店客户端      PostgreSQL
    │              │              │              │
    │  1. 执行命令 │              │              │
    │─────────────►│              │              │
    │              │  2. 查找门店 │              │
    │              │  WebSocket   │              │
    │              │─────────────►│              │
    │              │              │  3. 执行命令 │
    │              │◄─────────────│              │
    │              │  4. 返回结果 │              │
    │◄─────────────│              │              │
    │              │              │              │
    │              │  5. 记录审计日志            │
    │              │─────────────────────────────►│
```

### 远程桌面连接流程

```
Web 前端      浏览器      RustDesk客户端      RustDesk Server      门店客户端
    │            │              │                   │                  │
    │ 点击连接   │              │                   │                  │
    │───────────►│              │                   │                  │
    │            │ rustdesk://  │                   │                  │
    │            │─────────────►│                   │                  │
    │            │              │  请求门店 ID      │                  │
    │            │              │──────────────────►│                  │
    │            │              │  返回门店地址     │                  │
    │            │              │◄──────────────────│                  │
    │            │              │  P2P 直连尝试     │                  │
    │            │              │─────────────────────────────────────►│
    │            │              │  连接成功/中继    │                  │
    │            │              │◄─────────────────────────────────────│
```

## 网络端口汇总

### 总部服务器

| 端口 | 协议 | 用途 |
|------|------|------|
| 443 | HTTPS | Web 管理平台、WSS |
| 5432 | PostgreSQL | 数据库（内网） |
| 8080 | HTTP | 后端服务（内网，Nginx 代理） |
| 21115 | TCP | RustDesk hbbs |
| 21117 | TCP | RustDesk hbbr |
| 21119 | TCP | RustDesk hbbr |

### 门店客户端出站

| 端口 | 用途 |
|------|------|
| 443 | WebSocket 连接、API 调用 |
| 21115 | RustDesk ID 注册 |
| 21117/21119 | RustDesk 中继 |
