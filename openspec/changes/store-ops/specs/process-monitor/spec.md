## 新增需求

### 需求:IT人员可查看门店进程列表

总部 IT 人员必须能够在 Web 管理平台查看门店电脑正在运行的进程列表。

#### 场景:获取进程列表
- **当** IT 人员点击门店的"查看进程"按钮
- **那么** 系统向门店客户端请求进程列表
- **那么** 进程列表返回并显示在 Web 界面
- **那么** 列表包含进程名称、PID、CPU 使用率、内存使用率

#### 场景:刷新进程列表
- **当** IT 人员点击"刷新"按钮
- **那么** 系统重新获取最新进程列表

#### 场景:进程列表排序
- **当** IT 人员点击列表头部的"CPU"或"内存"列
- **那么** 进程列表按该列排序

### 需求:IT人员可终止进程

IT 人员必须能够远程终止门店电脑上的进程。

#### 场景:终止进程
- **当** IT 人员在进程列表中选择某个进程
- **当** IT 人员点击"终止进程"按钮
- **那么** 系统弹出确认对话框
- **当** IT 人员确认终止
- **那么** 进程终止请求发送到门店客户端
- **那么** 进程被终止
- **那么** 进程列表自动刷新

### 需求:可查看Windows服务状态

IT 人员必须能够查看门店电脑的 Windows 服务状态。

#### 场景:获取服务列表
- **当** IT 人员切换到"服务"标签页
- **那么** 系统向门店客户端请求服务列表
- **那么** 服务列表返回并显示在 Web 界面
- **那么** 列表包含服务名称、显示名称、状态（运行/停止）

#### 场景:启动/停止服务
- **当** IT 人员选择某个服务
- **当** IT 人员点击"启动"或"停止"按钮
- **那么** 系统发送服务控制请求到门店客户端
- **那么** 服务状态更新
