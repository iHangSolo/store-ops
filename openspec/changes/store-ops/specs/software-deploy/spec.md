## 新增需求

### 需求:IT人员可推送软件安装

总部 IT 人员必须能够向门店电脑推送软件安装包并执行安装。

#### 场景:推送安装包
- **当** IT 人员上传软件安装包（如 `.exe` 或 `.msi`）
- **当** IT 人员选择目标门店
- **当** IT 人员点击"推送安装"按钮
- **那么** 安装包传输到门店客户端
- **那么** 门店客户端执行安装
- **那么** 安装结果返回并显示在 Web 界面

#### 场景:批量推送安装
- **当** IT 人员选择多个门店
- **当** IT 人员推送软件安装
- **那么** 安装包依次推送到每个门店
- **那么** 每个门店的安装结果独立显示

### 需求:支持静默安装参数

软件推送必须支持配置静默安装参数，实现无感安装。

#### 场景:配置静默安装参数
- **当** IT 人员推送软件安装
- **当** IT 人员填写静默安装参数（如 `/S` 或 `/quiet`）
- **那么** 门店客户端使用该参数执行静默安装

### 需求:推送安装进度显示

系统必须显示软件推送和安装的进度状态。

#### 场景:查看安装进度
- **当** 软件正在推送到门店
- **那么** Web 界面显示"传输中"状态及进度百分比
- **当** 软件传输完成
- **那么** 状态变为"安装中"
- **当** 安装完成
- **那么** 状态变为"安装成功"或"安装失败"

### 需求:门店离线时推送失败提示

#### 场景:向离线门店推送软件
- **当** IT 人员向门店推送软件
- **当** 该门店客户端离线
- **那么** 系统提示"门店离线，无法推送"
