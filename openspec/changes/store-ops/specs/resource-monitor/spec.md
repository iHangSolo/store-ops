## 新增需求

### 需求:门店客户端上报资源数据

门店客户端必须定期采集并上报本机的资源使用数据到总部服务器。

#### 场景:定时上报资源数据
- **当** 门店客户端运行中
- **那么** 每 30 秒采集一次 CPU、内存、磁盘使用率
- **那么** 数据通过 WebSocket 连接上报到总部服务器

#### 场景:上报数据内容
- **当** 门店客户端上报资源数据
- **那么** 数据包含 CPU 使用率（百分比）
- **那么** 数据包含内存使用率（百分比）和可用内存（GB）
- **那么** 数据包含磁盘使用率（百分比）和可用空间（GB）

### 需求:Web平台显示门店资源状态

Web 管理平台必须显示各门店电脑的资源使用状态。

#### 场景:门店列表显示资源概览
- **当** IT 人员查看门店列表
- **那么** 每个门店显示 CPU、内存、磁盘使用率的概览数据
- **那么** 使用率超过 80% 的指标以红色高亮显示

#### 场景:查看门店资源详情
- **当** IT 人员点击某个门店的"资源监控"按钮
- **那么** 显示该门店的详细资源信息
- **那么** 包含 CPU 使用率趋势图（最近 1 小时）
- **那么** 包含内存使用率趋势图（最近 1 小时）
- **那么** 包含各磁盘分区的使用情况
